按你设的条件筛选 BOSS 直聘的岗位并自动发起沟通（投递）。纯本地运行，没有后端，配置和统计只存在你自己浏览器里。

同一份逻辑有**两种装法**，随便挑一个：

| | 装法 | 需要开发者模式 | 改代码后 |
| --- | --- | --- | --- |
| Chrome 扩展 | `chrome://extensions/` → 加载已解压的扩展程序 | 需要 | 回扩展页点刷新 |
| 油猴脚本 | Tampermonkey → 新建脚本 → 粘贴 `dist/boss-auto-apply.user.js` | **不需要** | 重新粘贴一次 |

两者共用 `src/shared/defaults.js`、`src/content/filters.js`、`src/content/panel.js` —— 面板代码只通过 `window.__BOSS_EXT__` 这个口用扩展能力，油猴版由 `tools/userscript-shim.js` 实现这个口。**不是两套实现，改一处两边都改到。**

## 它怎么干活

```
在岗位列表页点「开始」
   │
   ├─ 1. 从接口取一整页岗位（30 个）
   │     /wapi/zpgeek/search/joblist.json      ← 页面上有搜索词时
   │     /wapi/zpgeek/pc/recommend/job/list.json ← 没有搜索词（推荐流）
   │     一次拿全：岗位名/公司/薪资/城市/是否已沟通/猎头标记
   │
   ├─ 2. 第一道筛选（零额外请求）
   │     关键词、排除词、排除公司、城市、薪资、是否已沟通、猎头
   │
   ├─ 3. 只给过第一道的岗位拉详情
   │     /wapi/zpgeek/job/card.json?securityId=&lid=
   │     列表接口不给「HR 活跃度」和「JD 正文」，只有这个接口给
   │
   ├─ 4. 第二道筛选（活跃度、JD 正文排除词）
   │
   └─ 5. 投递：/wapi/zpgeek/friend/add.json?securityId=&jobId=
         BOSS 网页上点「立即沟通」走的就是这个接口
```

**为什么这么设计**：一页 30 个岗位，如果每个都拉一次详情，就是 30 次请求；先过第一道，通常只剩几个，请求量降一个数量级（离线演练里 7 个岗位只发了 4 次详情请求）。而且**整个主流程不碰页面 DOM** —— BOSS 前端改版不会把筛选搞坏，最多是面板显示不出来。

DOM 只在两种情况下用：判断"这是不是岗位列表页"，以及**接口取不到列表时兜底**（按页面上的岗位卡片 + 「下一页」按钮走）。

## 装哪个、怎么用

### 方式一：油猴脚本（不需要开发者模式）

1. Chrome 应用商店装 [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
2. Tampermonkey 图标 → 管理面板 → **+** 新建脚本
3. 打开 `dist/boss-auto-apply.user.js`，全选内容，覆盖掉新建脚本里的模板，Ctrl+S 保存
4. 打开 BOSS 直聘岗位列表页，右下角出现青色面板

### 方式二：Chrome 扩展

1. `chrome://extensions/` → 右上角打开「**开发者模式**」
   （注意：这个开关在**扩展程序管理页**，不在 `chrome://settings` 里；跟按 F12 的「开发者工具」是两回事）
2. 左上角点「**加载已解压的扩展程序**」→ 选 `boss-auto-apply` 这个目录
3. 打开 BOSS 直聘岗位列表页，右下角出现青色面板
4. 改过代码后要回这个页面点一下卡片上的**刷新按钮**，Chrome 不会自动重读已解压扩展的文件

## 推荐：用一个专用浏览器跑（双击 `启动BOSS专用浏览器.bat`）

理由见下面「BOSS 会探测你本机的自动化工具」那节：它会在服务端记你的浏览器指纹和本机自动化端口。所以最好给它一个干净的浏览器，里面只有这一个插件。

这个 bat 做的事：

- 用**独立的 profile**（`%LOCALAPPDATA%\BossToolProfile`）启动 Chrome —— 你在常用 profile 里装的扩展（含各种自动化工具）一个都不会跟过来
- **不挂任何调试端口**，它那套 `127.0.0.1:9222 / 18789 / 10086 / 8642` 探测扫不到东西
- 直接打开 BOSS 岗位列表页

**需要手工做一次的**：Chrome 155 起已经禁止用命令行 `--load-extension` 侧载扩展了（实测：Chrome 日志直接报 `--disable-extensions-except is not allowed in Google Chrome, ignoring.`，扩展也不会被登记）。所以第一次要在那个窗口里装一次插件 —— bat 会自动帮你打开 `chrome://extensions/`，你点三下就行（开发者模式 → 加载已解压的扩展程序 → 选 `boss-auto-apply` 目录）。装完它记住，以后这个 bat 只开窗口、不再弹扩展页（它靠查 profile 的 `Secure Preferences` 判断）。

装完在专用窗口里扫码登录一次 BOSS，之后就用这个窗口跑投递。

## 状态会写在标签页标题上

打开岗位列表页后，**什么都不用点**，插件会自动探一次并把结论写进标签页标题：

```
[就绪 路径OK tokenOK 列表30]  BOSS直聘
[就绪 路径OK token读不到]     BOSS直聘      ← 没登录 / 登录过期
[就绪 路径OK 接口失败:code=1]  BOSS直聘      ← 接口被拒
[投3/扫7/跳4/失0 完]          BOSS直聘      ← 跑完一轮的结果
```

为什么费劲写这个：BOSS 的页面在自动化环境里会被它自己 `window.close()` 掉，所以想远程看现场，只剩「读标签页标题」这条不需要碰页面的路。顺带也是个真有用的东西 —— 切到别的标签页也能瞟见跑到哪了。日志同时也镜像一份到 DevTools console，前缀 `[boss-auto-apply]`。

自动探测只花**一个**接口请求，用的是页面自己也在调的同一个接口。

## 手动自检

面板上的「自检」只读页面 + 只调接口，**不投递任何东西**，会打这样一份报告：

```
路径：/web/geek/jobs
搜索条件（从当前地址读）：{"query":"Java","city":"101240700"}
isJobListPage()（能开跑吗）→ true
token（bst cookie）：读到，长度 108
—— 接口取列表（主路径）——
接口取列表成功（来源：搜索）→ 30 个岗位，hasMore=true
首条：Java 后端开发工程师 @ 云启科技｜25-40K·14薪｜contact=false｜goldHunter=0｜jobValidStatus=1
首条第一道判定：通过（会去拉详情跑第二道）
—— 页面 DOM（只在接口失败时当兜底用）——
```

它一眼能区分出卡在哪一环：路径不对 / token 读不到 / 接口失败 / 筛选条件把岗位全滤掉了。报告里 token 那行**只报长度，不打印内容**。

## 配置项

在**选项页**（扩展版）或**面板上的「设置」浮层**（油猴版）里改，两处字段完全一样。

| 配置 | 说明 |
| --- | --- |
| 试运行 | 只筛选 + 记日志，不真投。**默认开** |
| 岗位名必须包含 | 逗号分隔，命中任意一个即可；留空 = 不限 |
| 排除词 · 岗位名或公司名 | 命中就跳过 |
| 排除词 · 岗位描述正文 | 挡挂羊头卖狗肉的岗位 |
| 排除公司 | 黑名单 |
| 城市 | 留空不限；区县名也能命中 |
| 薪资上/下限 | 单位 K/月；`20-40K·14薪`、`2-3万`、`200-300元/天`（按 21.75 天折月）都能解析 |
| 活跃度 | 只投「最近 N 天内活跃」的 HR |
| 跳过已沟通 | 默认开（看接口的 `contact` 与详情的 `friendStatus`） |
| 同一招聘者不重复打招呼 | **默认开、30 天**。同一个 HR 常挂着好几个岗位，只按岗位去重的话他会连收好几条一样的招呼语 —— 这是最容易被当成骚扰举报的形态。设 0 = 只在本轮内去重 |
| 跳过猎头 | 默认关（接口的 `goldHunter` 是字符串 `"0"/"1"`） |
| 每日最多投递 | 默认 60，**上限夹到 150**（BOSS 硬上限） |
| 每次投递间隔 | 随机取值，默认 2–5 秒 |
| 最多自动翻页 | 默认 20 页（按接口的 `page` 翻，不是点按钮） |
| 自动确认 120 提示 | 默认关，遇到就停下等你 |

几个刻意的约定：

- **薪资/活跃度解析不出来时，如果你设了对应区间就跳过**，并在日志里带上原文（方便发现 BOSS 改文案）。没设区间的维度不管。
- 跨午夜当天计数自动归零。
- 关键词匹配**大小写不敏感**（写 `java` 也能命中「Java 后端开发」）。

## 切到「消息」页也不会中断投递

BOSS 的「职位 → 消息」是**整页跳转**（不是单页路由切换），文档被重新加载。而插件的运行状态是「每次页面加载一份」，所以：

- 旧版：一跳到消息页，这一轮就断了，而且**面板压根不会挂出来**（只在职位列表页挂），你连"它停了"都看不见
- 现在：一轮投递会**落盘成会话**（起始时间、跑到第几页、本轮已处理过哪些岗位、开始那一刻冻结的搜索条件），整页重载后 4 秒自动接着跑；面板在投递中于任何 BOSS geek 页面（职位/推荐/消息/简历…）都会显示

三个关键点：

1. **不重复投**。本轮已处理过的岗位 id 跟着会话走，续跑时直接跳过。定时器也做了处理：结束时的落盘会先取消挂起的延迟写，避免把 `active:true` 又写回去。
2. **条件不漂**。续跑用的是「点开始那一刻冻结的搜索条件」，不是当场读地址栏 —— 否则你在消息页续跑时，地址栏里没有 `query`，就会莫名其妙从"搜索结果"漂成"推荐流"。
3. **只有本标签页自己的会话才续跑**。标签页 id 存在 `sessionStorage`（跨整页重载保留、新标签页是新值），所以重载/切页面能续上，新开的标签页不会去接别人那轮；后台还有一道"同一浏览器同时只允许一个页面在投递"的锁。

兜底：不想续跑就点面板上的「停止」，会话会立即标记结束。

## BOSS 会探测你本机的自动化工具（实测）

翻它自己的安全脚本 `static.zhipin.com/zhipin-geek/security/<版本>/geek/index.js` 看到的：它会**探测本机固定几个端口**，命中就上报到它自己的 APM 接口：

| 探测目标 | 上报码 |
| --- | --- |
| `127.0.0.1:18789` | 410001 |
| `127.0.0.1:9222`（Chrome 远程调试端口） | 410003 |
| `ws://127.0.0.1:10086/ws` | — |
| `http://127.0.0.1:8642/v1/health` | 410009 |

这些探测**真的会跑**：我抓包时就看到过一条 `GET http://127.0.0.1:8642/v1/health → ERR_CONNECTION_REFUSED`。

同时它还会采集 WebGL 渲染器、canvas、插件列表、语言、鼠标轨迹等指纹，一并上报。

**注意事项**：

- **`chrome://extensions` 里的「开发者模式」开关，网站看不见** —— 那是 Chrome 自己的界面状态，没有任何 API 暴露给网页。你之前怀疑的"开发者模式导致刷新"不是这个开关。
- **真正会被看见的是调试器/自动化工具**：按 F12 开 DevTools、用 `--remote-debugging-port` 启动 Chrome、或者挂 CDP 的工具（Playwright、chrome-devtools-mcp、以及任何申请了 `debugger` 权限的扩展）。上面那串端口探测就是冲这些来的。
- 客户端脚本**只上报、不做拦截**（我通读了那个安全脚本和主 bundle：里面唯一的 `location.reload()` 绑定的是"登录成功"，没有"检测到风险就刷新/跳转"的逻辑）。所以**服务端拿到这些指纹之后做了什么，从外面看不到** —— 风控分级、限流、乃至封号都可能发生在这之后。
- 插件这边做了什么：面板挂在 `body` 下、id 用中性的 `__aa_panel`（不再把 `boss-auto-apply` 这种自报家门的字符串留在页面里），界面在 Shadow DOM 里、不改动页面自身结构。**但要说清楚：Shadow DOM 是 open 模式，页面脚本理论上仍能顺着这个节点读到面板内容**（标题、状态、日志）。所以这里的"隐蔽"是有限的 —— 真正让指纹干净的是**不挂调试端口、不装其他自动化工具**（即上面那个专用浏览器），而不是指望页面发现不了这个面板。

**建议的用法**：给 BOSS 单独开一个 Chrome 配置文件（profile），这个 profile 里不要装其他自动化扩展，用的时候别开 F12。

## 风控与风险

这类工具违反 BOSS 直聘的用户协议，**有账号被限流/降权/封号的可能**，成熟的开源项目 README 里也都写着风险自担。能压的我都压了：

- 默认试运行，不会一装上就开始投
- 间隔随机 + 可配，不以机器速度连点
- 自设每日上限，默认 60（远低于 BOSS 的 120）
- 命中限流文案自动暂停 30 秒；命中上限文案（120/150 位）直接停，不硬闯
- 登录态失效（401/403）立刻停，不会把剩下几十个岗位刷成一串失败
- **同一个浏览器同一时间只允许一个标签页投递**（跨页面上锁，抢跑那个拒绝启动）
- 不碰聊天消息通道，不做自动回复

**招呼语**用的是你 BOSS 账号里的「默认打招呼语」（我的 → 设置 → 打招呼语）。插件不发送自定义消息 —— 那要走 BOSS 的 WebSocket 私有协议，脆弱且更容易招风控，收益不值这个风险。

建议先小批量跑（上限设 10）观察几天，再加量。

## 权限

扩展版只申请：`storage`、`cookies`（读 `bst` token）、`clipboardWrite`（复制日志），外加 host 权限 `https://*.zhipin.com/*`。**没有** `tabs`、**没有** `<all_urls>`、**不碰** `debugger`。注入范围只有 `/web/geek/*` 和 `/job_detail/*`。

油猴版由 Tampermonkey 托管，`@match` 范围同上。

## 排查：日志会落一份到 storage

面板的日志除了显示在界面上、镜像到 DevTools console，还会**节流写一份到 `chrome.storage.local`**（键 `bossAutoApply.diag`）：最近一次探测结论（路径是否对、token 是否读到、列表拿到几个、失败原因）+ 最近 80 行日志。

为什么要多写这一份：它让排查**不用打开 DevTools、也不用人工复制日志** —— 直接从浏览器 profile 的 `Default/Local Extension Settings/<扩展id>/` 里就能读出来（那里面是 leveldb，值是明文）。装专用浏览器那套（见上）时尤其有用，因为那个进程没有别的工具能挂进去。

注意：这份快照是明文存在本机的，内容包含岗位名/公司名这类运行信息（**不含** token —— token 只在内存里用、不落盘）。

## 隐私

- **不联系任何第三方**：全仓库唯一会出网的是 `www.zhipin.com` 自己的接口（列表 / 详情 / 发起沟通）。没有埋点、没有统计上报、没有 CDN。
- **不收集你的数据**：没有服务端，代码里没有任何把数据发到别处的地方。
- **token 不落盘**：`bst` 只在内存里用来发请求，不写 storage、不进日志（自检只报"读到，长度 N"）。
- **本地存了什么**：配置、当日统计、以及一份诊断快照（最近一次探测结论 + 最近 80 行日志）。**这份快照是明文存在你本机的**，内容包含岗位名/公司名这类运行信息。位置：扩展版在浏览器 profile 的 `Local Extension Settings/<扩展id>/`，油猴版在 Tampermonkey 的存储里（没有 Tampermonkey 存储时退化为 localStorage）。
- **申请了哪些权限**：`storage`、`cookies`（只为读 `bst`）、`clipboardWrite`（"复制日志"按钮用），host 权限只到 `https://*.zhipin.com/*`。**没有** `tabs`、没有 `<all_urls>`、**没有** `debugger`。

**变异验证**：逐个破坏「万的换算」「已沟通过滤」「薪资下限」「关键词大小写归一」「dryRun 归一」「delayMax 夹取」「每日上限夹取」「换天归零」「第一道不跳过活跃度」「第一道不跳过 JD 排除词」「第一道不跳过 includeInJd」「猎头不认字符串 "1"」等 16 处代码，每处都有对应用例变红。有两次第一次没咬住，都查出来是**用例太弱**而不是代码没问题，已修：

- 拿默认值就是 `true` 的字段去验 `1 → true`，归一失效时会被默认值兜住 → 改用默认值为 `false` 的字段
- 廉价阶段 JD 恒为空，测不出"不读 JD"和"读不到 JD"的差别 → 改成**故意给列表条目塞一份 JD**，才真正锁住语义

**离线端到端**：`tools/fixture.html` 是假的 BOSS 列表页 + 假接口，支持三种环境（扩展版 / 油猴桩 / **油猴构建产物本体**）。三种环境跑同一组用例，结果逐条一致：7 扫描 / 3 投递 / 4 跳过、跳过原因全部正确、`card.json` 只发 4 次（不是 7 次）、按接口 `page` 翻页、`hasMore=false` 时停止。

已经用夹具抓到过两个真 bug：一是 `closest('[class*="job-card"]')` 会把**锚点自己**选中（锚点 class 就叫 `job-card-left`），导致公司名读不出来；二是拼接油猴单文件时的 **ASI 陷阱**（前一段 IIFE 结尾没分号，后一段以 `(function` 开头被当成函数调用，产物直接报 `is not a function`）—— 现在构建脚本会强制校验这个不变量，不合格直接拒绝生成。
